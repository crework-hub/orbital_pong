# Telegram-бот «Орбитальная симуляция» (ЛР 3)

Бот-помощник для игры **Orbital Pong** (вариант 15). Игра остаётся в Pygame, а бот работает с её данными и считает физику.

## Что делает бот

1. **Симуляция полёта мяча.** Спрашивает массу чёрной дыры и начальный вектор мяча (vx, vy), считает траекторию по формуле из задания `F = G·M / d²`, рисует GIF через Pillow и присылает его с вердиктом: мяч **совершил оборот**, **упал в дыру** или **улетел**.
2. **Таблица лидеров.** Принимает `records.csv`, который пишет сама игра, проверяет каждую строку и собирает общий рейтинг самых быстрых побед.
3. **Статистика пользователя.** Сколько запусков было, сколько раз мяч сделал оборот, лучший угол вокруг дыры.
4. **Подписка на уведомления.** Когда кто-то загружает новые рекорды, подписчики получают сообщение.

## Запуск

```bash
cd orbital_pong/py_bot

# 1. зависимости
pip install aiogram==3.31.0 python-dotenv pillow

# 2. токен бота: создать файл .env рядом с bot.py
#    BOT_TOKEN=123456789:AA...   (токен даёт @BotFather командой /newbot)

# 3. запуск
python bot.py
```

Без токена бот не стартует и прямо об этом пишет — так токен случайно не попадёт в репозиторий.

## Как устроено

**Stateless-сессии.** Бот не держит состояние в памяти. Всё про пользователя (какой экран открыт, какая масса введена, подписан ли он) лежит в `sessions/<user_id>.json`:

```json
{
  "state": "MENU",
  "screen_message_id": 42,
  "screen_chat_id": 777,
  "mass": 6.0,
  "subscribed": false
}
```

Свой файл у каждого — сессии разных людей не пересекаются.

**Один экран вместо потока сообщений.** Бот запоминает `message_id` своего сообщения и обновляет его через `edit_message_text`. Если текст не изменился, Telegram возвращает `message is not modified` — это не ошибка, бот её молча пропускает.

**FSM.** Состояния `menu → wait_mass → wait_vector` (и `wait_file` для загрузки). Без `StateFilter` обработчик ввода ловил бы любые сообщения в любой момент.

**Проверка данных.** Масса от 0.1 до 1000, скорость от −20 до 20, в CSV проверяются имя, счёт вида `5:3` и время числом. Битые строки пропускаются, бот не падает.

**Безопасность.** Все данные из чата считаются недоверенными: числа парсятся регуляркой и проверяются по границам, размер файла ограничен 1 МБ, ошибки обработчиков ловятся в `@dp.errors()`.

**Логирование.** Всё пишется в `bot_flight.log` с временем и уровнем: старт, симуляции, загрузки, ошибки.

## Как проверить без Telegram

```bash
python -c "from simulation import run_simulation; print(run_simulation(6, 3, 1)['verdict'])"
```

Ответ `orbit` значит, что мяч при массе 6 и векторе (3, 1) сделал полный оборот вокруг дыры. Для сравнения: масса 2 и вектор (4, 0) — `fell`, мяч падает в дыру.
