Как проверить

  1. Откройте страницу — в таблице 2 демо-аномалии.
  2. Введите массу 5000 и нажмите «Добавить» — появится ошибка, запись не создастся.
  3. Исправьте массу на 50 — запись появится в таблице и на превью.
  4. Нажмите «Изменить», поменяйте массу, «Сохранить» — значение обновится.
  5. Сдвиньте ползунок массы — счётчик «Показано N из M» уменьшится.
  6. Удалите запись, перезагрузите страницу (F5) и проверьте DevTools → Application → Local Storage → orbital_pong_anomalies.
