# Orbital Pong — CRUD «Космические аномалии» (ЛР 6)

**Студент:** Гакуть М.А., группа 25-СТ · **Предмет:** СЯП · **Вариант 15**

Веб-интерфейс администратора для игры Orbital Pong (пинг-понг с чёрной дырой в центре). Здесь можно добавлять на поле гравитационные объекты — чёрные дыры (притягивают мяч) и белые дыры (отталкивают), смотреть их в таблице, менять координаты, массу и тип, удалять. Всё сохраняется в `localStorage`, и ЛР 7 читает эти данные в самой игре.

## Запуск

ES-модули не работают через `file://`, поэтому нужен статический сервер:

```bash
cd orbital_pong          # корень проекта, где лежит папка crud/
python3 -m http.server 8000
```

Открыть в браузере: <http://localhost:8000/crud/>

Внешних библиотек, CDN и сборщиков нет — чистые HTML, CSS и JS.

## Поля сущности

| Поле | Тип | Обязательное | Ограничения |
|---|---|---|---|
| `id` | строка (UUID) | создаётся автоматически | только `crypto.randomUUID()` |
| `name` | строка | да | 2–30 символов; буквы, цифры, пробел, дефис |
| `type` | строка | да | `black` (притягивает) или `white` (отталкивает) |
| `x` | число | да | 0–800 |
| `y` | число | да | 0–600 |
| `mass` | число | да | 0.1–1000, можно дробное (запятая тоже понимается) |
| `createdAt` | строка ISO | автоматически | время создания |

## Валидация

Одна функция `validateAnomaly()` в `js/validate.js` используется и для формы, и для инлайн-редактирования. Она возвращает объект ошибок вида `{ mass: "Масса: от 0.1 до 1000" }`. Если он не пустой:
- в форме поля подсвечиваются красным, текст ошибки виден под полем, форма **не** сбрасывается, запись не создаётся;
- в строке таблицы ошибки показываются прямо в ячейках, запись в хранилище **не** меняется.

Имя проверяется регуляркой `/^[\p{L}\d\s-]+$/u` (любые буквы Unicode, поэтому кириллица проходит).

## Хранение

Ключ: `orbital_pong_anomalies`. Значение — JSON-массив:

```json
[
  { "id": "3f1c…", "name": "Центральная чёрная дыра", "type": "black", "x": 400, "y": 300, "mass": 10, "createdAt": "2026-11-04T18:00:00.000Z" },
  { "id": "9a2b…", "name": "Белая дыра-отражатель", "type": "white", "x": 200, "y": 150, "mass": 4, "createdAt": "2026-11-04T18:00:00.000Z" }
]
```

Если ключа нет, массив пустой или JSON битый — записываются эти две демо-записи. Кнопка «Сбросить к демо-данным» (с подтверждением) делает то же самое вручную. После каждого добавления, изменения и удаления массив сразу сохраняется, а таблица, счётчик и превью перерисовываются.

## Как тестировать

1. Откройте страницу — в таблице 2 демо-аномалии, на превью две точки.
2. Заполните форму, массу поставьте 5000, нажмите «Добавить аномалию» — под массой появится ошибка, записей останется 2.
3. Исправьте массу на 50 — запись появится в таблице и на превью, счётчик «Показано 3 из 3».
4. Нажмите «Изменить» у новой записи, впишите массу `-1` и «Сохранить» — ошибка в строке. Впишите 77.5 и сохраните — значение обновилось. Пока строка редактируется, «Изменить» у другой строки не сработает (появится подсказка), так что несохранённые правки не теряются.
5. Сдвиньте ползунок «Минимальная масса» до 20 — останется 1 строка, «Показано 1 из 3». Число рядом с ползунком меняется синхронно. Поиск по названию и фильтр по типу тоже работают.
6. Нажмите «Удалить», подтвердите — запись пропадёт.
7. Нажмите F5 — данные на месте. DevTools → Application → Local Storage → `http://localhost:8000` → `orbital_pong_anomalies` покажет JSON-массив.
8. XSS: в консоли выполните `escapeHtml('<img src=x onerror=alert(1)>')` — вернётся `&lt;img src=x onerror=alert(1)&gt;`. Если подложить такое имя прямо в localStorage, в таблице будет виден текст, а не картинка.

## Соответствие требованиям ЛР 6

| № | Требование | Где в коде |
|---|---|---|
| 1 | Отдельная HTML-страница CRUD | `crud/index.html` |
| 2 | Create: форма с валидацией | форма `#add-form` в `index.html`, обработчик `submit` в `js/app.js`, правила в `js/validate.js` |
| 3 | Read: таблица и фильтр по числовому полю | `renderTable()` в `js/table.js`; ползунок + число `#f-mass`/`#f-mass-num`, поиск и тип — `filtered()` в `js/app.js` |
| 4 | Update: инлайн-редактирование с валидацией | `editRow()` / `readRowInputs()` в `js/table.js`, действия `edit`/`save`/`cancel` в `js/app.js` |
| 5 | Delete с подтверждением | действие `delete` в `js/app.js` (`confirm()` с названием записи) |
| 6 | LocalStorage, фиксированный ключ | `STORAGE_KEY`, `saveAnomalies()` в `js/store.js`, вызов через `commit()` в `js/app.js` |
| 7 | UUID через `crypto.randomUUID()` | `js/app.js` (создание), `js/store.js` (демо-записи) |
| 8 | XSS-защита через escapeHtml | `escapeHtml()` в `js/table.js`, через неё идут все значения в `innerHTML` |
| 9 | Структура index.html / css / js | ES-модули, `<script type="module" src="js/app.js">` |
| 10 | README | этот файл |

Бонус: превью поля на Canvas (`js/render.js`) — размер точки зависит от массы, цвет от типа.
