# Orbital Pong — CRUD «Космические аномалии» (ЛР 6)

**Студент:** Гакуть М.А., группа 25-СТ · **Предмет:** СЯП · **Вариант 15**

Веб-панель администратора для управления гравитационными объектами игрового поля. По варианту 15:

> Написать веб-интерфейс для управления «Космическими аномалиями». Администратор может добавлять на поле новые гравитационные объекты (черные или белые дыры, которые отталкивают мяч), просматривать их список в таблице, изменять их координаты, массу/тип и удалять. Все объекты сохраняются в localStorage.

Чёрная дыра притягивает мяч, белая — отталкивает.

## Запуск

Скрипты подключены обычными тегами `<script>`, без ES-модулей, поэтому страницу можно открыть двумя способами.

**Вариант 1.** Просто открыть файл `crud/index.html` в браузере (двойной щелчок).

**Вариант 2.** Из корня репозитория:

```bash
python -m http.server 8000
```

Затем открыть <http://localhost:8000/crud/>.

Внешних библиотек и сборщиков нет — только HTML, CSS и JavaScript.

## Поля сущности

Сущность — космическая аномалия (гравитационный объект на поле 800×600).

| Поле | Тип | Обязательное | Ограничения |
|---|---|---|---|
| `id` | строка (UUID) | создаётся автоматически | только `crypto.randomUUID()` |
| `name` | строка | да | 2–30 символов; буквы, цифры, пробел, дефис |
| `type` | строка | да | `black` (притягивает) или `white` (отталкивает) |
| `x` | число | да | 0–800 |
| `y` | число | да | 0–600 |
| `mass` | число | да | 0.1–1000, можно дробное (запятая тоже подходит) |

Название в варианте явно не перечислено, но оно нужно для поиска по таблице (требование методички ЛР 6) и чтобы записи отличались в списке. Координаты, масса и тип — из формулировки варианта.

## Валидация

Одна функция `validateAnomaly()` в `js/validate.js` используется и в форме создания, и при инлайн-редактировании. Если проверка не прошла:

- в форме ошибки появляются под полями, форма не очищается, запись не создаётся;
- в строке таблицы ошибки видны в ячейках, запись в хранилище не меняется.

На полях также стоят HTML5-атрибуты `required` / `min` / `max`. У формы есть `novalidate`, поэтому сообщения показывает наш JS, а не встроенные подсказки браузера.

## Хранение

Ключ: `orbital_pong_anomalies`. Значение — JSON-массив:

```json
[
  { "id": "3f1c…", "name": "Центральная чёрная дыра", "type": "black", "x": 400, "y": 300, "mass": 10 },
  { "id": "9a2b…", "name": "Белая дыра-отражатель", "type": "white", "x": 200, "y": 150, "mass": 4 }
]
```

Если ключа нет или JSON битый, записываются три демо-аномалии. После каждого добавления, изменения и удаления массив сразу сохраняется целиком (`saveAnomalies`), затем таблица перерисовывается.

## Как тестировать

1. Откройте страницу — в таблице три демо-аномалии, счётчик «Показано 3 из 3».
2. В форме оставьте название пустым или поставьте массу `5000` и нажмите «Добавить» — под полем появится ошибка, записей по-прежнему три.
3. Заполните форму корректно (например, название «Дыра Бета», тип «Белая», X `100`, Y `80`, масса `50`) — запись появится в таблице, счётчик станет «Показано 4 из 4».
4. Нажмите «Изменить», впишите массу `-1` и «Сохранить» — ошибка в строке, значение не меняется. Впишите `77.5` и сохраните — масса обновится. «Отмена» возвращает строку без сохранения.
5. Сдвиньте ползунок «Минимальная масса» до `20` — останутся записи с массой ≥ 20, число рядом с ползунком меняется сразу. Поиск по названию тоже работает.
6. Нажмите «Удалить» и подтвердите в диалоге — запись исчезнет. Если нажать «Отмена» в диалоге, запись останется.
7. Нажмите F5 — данные на месте. DevTools → Application → Local Storage → ключ `orbital_pong_anomalies` покажет актуальный JSON-массив.
8. XSS: добавьте запись с названием `<img src=x onerror=alert(1)>`. В таблице должен быть виден текст, а не картинка. `escapeHtml` в `js/app.js` заменяет `<` на `&lt;` и т. д.

## Соответствие требованиям ЛР 6

| № | Требование | Где в коде |
|---|---|---|
| 1 | Отдельная HTML-страница CRUD | `crud/index.html` |
| 2 | Create: форма с валидацией всех полей | форма `#add-form`, обработчик `submit` в `js/app.js`, правила в `js/validate.js` |
| 3 | Read: таблица, поиск и фильтр-ползунок по числу | `renderTable()` / `filtered()` в `js/app.js`, `#f-search` и `#f-mass` |
| 4 | Update: инлайн-редактирование с валидацией | `editRow()`, действия `btn-save` / `btn-cancel` |
| 5 | Delete с подтверждением | `confirm()` в обработчике `btn-delete` |
| 6 | LocalStorage, фиксированный ключ, сохранение сразу | `STORAGE_KEY`, `saveAnomalies()` в `js/storage.js`, вызов из `commit()` |
| 7 | UUID через `crypto.randomUUID()` | создание записи в `js/app.js`, демо-данные в `js/storage.js` |
| 8 | XSS-защита через `escapeHtml` | `escapeHtml()` в `js/app.js`, все пользовательские строки в таблице идут через неё |
| 9 | Структура `index.html`, `css/`, `js/` | три модуля без ES-`import`, чтобы работал `file://` |
| 10 | README | этот файл |
